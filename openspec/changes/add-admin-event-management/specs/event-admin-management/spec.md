## ADDED Requirements

### Requirement: イベントの作成と編集
管理者はイベントの名前・説明・開催日時・画像・動画・Drive リンクを登録、編集、削除できる (SHALL)。

#### Scenario: イベントを作成する
- **WHEN** 管理者が名前と開催日時を入力してイベントを作成する
- **THEN** 下書き状態のイベントが作成される

#### Scenario: 開催日時の前後が逆
- **WHEN** 終了日時が開始日時より前の値で保存する
- **THEN** 保存されずにエラーが表示される

### Requirement: イベント一覧での状態表示
管理画面のイベント一覧は、各イベントの公開状態・作成日時・更新日時を表示する (SHALL)。

#### Scenario: 一覧を表示する
- **WHEN** 管理者が管理画面のイベント一覧を開く
- **THEN** 各イベントに下書き/公開のバッジと作成日時・更新日時が表示される

### Requirement: バンドと出演順の管理
管理者はイベントにバンドを追加、編集、削除し、出演順を並び替えられる (SHALL)。

#### Scenario: 出演順を並び替える
- **WHEN** 管理者がバンドの並びを変えて保存する
- **THEN** 公開ページでもその順にバンドが表示される

### Requirement: バンドメンバーの管理
管理者はバンドメンバーを追加し、表示名・パート・並び順を設定、削除できる (SHALL)。メンバーは登録ユーザーを選ぶか、Discord 未登録の人なら表示名だけで追加でき、行ごとにどちらかを必須とする。同じ登録ユーザーを 1 つのバンドに 2 回入れることはできない。

#### Scenario: 登録ユーザーをメンバーに追加する
- **WHEN** 管理者がユーザーを選んでパートを入力し保存する
- **THEN** そのユーザーがプロフィールへのリンク付きでバンドのメンバーとして表示される

#### Scenario: 未登録の人を表示名だけで追加する
- **WHEN** 管理者がユーザーを選ばずに表示名を入力して保存する
- **THEN** その名前がリンクなしでバンドのメンバーとして表示される

#### Scenario: ユーザーも表示名もない行は保存できない
- **WHEN** 管理者がユーザーも表示名も入れていない行を含めて保存する
- **THEN** その行にエラーが表示され、保存されない

### Requirement: 画像のアップロード
管理者はイベント画像とバンドの写真・画像・タイポ画像をアップロードして差し替えられる (SHALL)。管理者以外は画像保存先に書き込めない。

#### Scenario: イベント画像を差し替える
- **WHEN** 管理者が新しい画像をアップロードする
- **THEN** 新しい画像が表示され、古い画像は削除される

#### Scenario: イベントやバンドを削除すると画像も消える
- **WHEN** 管理者がイベントまたはバンドを削除する
- **THEN** その画像も保存先から削除され、URL を知っていても見られなくなる

### Requirement: レクリエーション王の設定
管理者はイベントのレクリエーション王を登録ユーザーから設定、解除できる (SHALL)。

#### Scenario: レク王を設定する
- **WHEN** 管理者がユーザーをレクリエーション王に設定する
- **THEN** イベントページにそのユーザーがレクリエーション王として表示される

### Requirement: 編集の即時反映
管理者が公開イベントを変更したら、公開ページのキャッシュを無効化する (SHALL)。

#### Scenario: 公開中のイベントを編集する
- **WHEN** 管理者が公開中のイベント名を変更する
- **THEN** 次に公開ページを開いたとき新しい名前が表示される
