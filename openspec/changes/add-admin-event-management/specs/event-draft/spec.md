## ADDED Requirements

### Requirement: 下書きイベントの非公開
下書きのイベントは公開ルート（イベント一覧・イベント詳細・バンド詳細）に表示してはならない (SHALL NOT)。管理者であっても公開ルートでは表示しない。

#### Scenario: 一覧に下書きが含まれない
- **WHEN** 誰かが `/events` を開く
- **THEN** 下書きのイベントは表示されない

#### Scenario: 下書きの詳細を直接開く
- **WHEN** 誰かが下書きイベントの `/events/[eventId]` を開く
- **THEN** 404 が表示される

### Requirement: 公開状態の切り替え
管理者はイベントを下書きから公開に、公開から下書きに切り替えられる (SHALL)。

#### Scenario: 下書きを公開する
- **WHEN** 管理者が下書きイベントを公開する
- **THEN** そのイベントが `/events` に表示される

### Requirement: 下書きのプレビュー
管理者は管理画面内で、公開ページと同じ見た目でイベントとバンドのページをプレビューできる (SHALL)。

#### Scenario: 下書きをプレビューする
- **WHEN** 管理者が下書きイベントのプレビューを開く
- **THEN** 公開ページと同じレイアウトで内容が表示され、下書きであることが分かる
